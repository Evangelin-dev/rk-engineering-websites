## Safe implementation completed

- Added a verified Organization/LocalBusiness JSON-LD block using the address, phone, email,
  and capabilities already displayed on the site.
- Added a `robots.txt` that allows crawling and points to the existing sitemap.
- Expanded the sitemap with core routes and all 36 product-detail routes.
- Added canonical coverage for all non-product-detail routes while retaining the existing
  product-detail canonical behavior.
- Improved home and core route metadata using only supported product, location, and export
  information.
- Added product JSON-LD to product-detail pages from existing product data.

## Recommendations requiring approval

- Create one consolidated JNPT export landing page covering cable trays, towers, solar
  structures, galvanized products, and logistics rather than thin keyword pages.
- Add visible location or JNPT copy only after approval and factual confirmation.
- Review the Africa and USA route families for consolidation before expanding city/country
  pages.
- Verify whether the company actively ships through Nhava Sheva/JNPT and which Incoterms are
  offered for each product before making those claims indexable.
